# module_servo

标准 PWM 舵机模块，把弧度角度或归一化命令映射为微秒脉宽，并通过 `bsp_pwm_t` 输出。

## 配置

`module_servo_config_t` 包含：

- PWM 基类；
- 输出频率；
- 最小、中位和最大脉宽，单位 us；
- 最小和最大机械角度，单位 rad；
- 逻辑名称与注册键。

中位脉宽单独配置，可适配机械中心不对称的舵机。

## 初始化和启动

```c
module_servo_init(&servo, &config);
module_servo_start(&servo);
module_servo_set_angle(&servo, target_angle_rad);
```

启动时配置 PWM 频率和安全初始输出。停止后输出行为仍取决于 BSP 平台的 PWM 安全状态。

## 控制接口

- `set_angle`：按角度范围映射脉宽；
- `set_normalized_output`：输入通常为 `[-1, 1]`，中点对应中位脉宽；
- `set_pulse_width`：直接设置微秒脉宽；
- `get_commanded_angle`：返回最后命令角，不是传感器实测角。

输入超出配置范围时按模块实现返回范围错误或限制，App 不应依赖舵机机械堵转来实现限位。

## 无反馈边界

普通 PWM 舵机没有位置反馈，本模块只是开环命令转换。需要闭环时应额外注入编码器，并在
更高层使用轴控制器；不能把命令角当作实际角度。

## 资源关系

多个舵机通道可能共享同一定时器频率。平台配置必须保证所有通道频率兼容。更新脉宽应使用
硬件预装载，避免中途产生异常脉冲。

## 建议验证

- 最小、中位和最大角度；
- 非对称脉宽映射；
- 归一化正负端点；
- 直接微秒脉宽；
- 超范围输入；
- 启停和安全输出；
- 多通道共享定时器。
