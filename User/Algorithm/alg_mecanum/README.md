# alg_mecanum

四轮麦克纳姆底盘运动学，支持 X/O 辊子布局、全向逆解、里程计正解、任意旋转中心和缺轮
降级。

## 轮序和几何

固定轮序为左前、右前、左后、右后。配置包含轮半径、半轴距、半轮距、各轮方向符号、
里程计权重、最大轮角速度和辊子排列。

几何参数均按轮子接地点相对车体原点定义。`ALG_MECANUM_ROLLER_X` 与
`ALG_MECANUM_ROLLER_O` 会改变横向速度系数。

## 初始化和逆解

```c
alg_mecanum_t model;
alg_mecanum_init(&model, &config);

alg_mecanum_inverse(
    &model,
    &body_velocity,
    wheel_is_available,
    wheel_velocity_rad_per_s,
    &applied_scale);
```

当任一可用轮超过最大轮速时，所有可用轮按相同比例缩放，保持运动方向。不可用轮输出零，
返回状态会反映是否降级。

## 任意旋转中心

`alg_mecanum_inverse_with_center_of_rotation` 接收旋转中心相对车体原点的 x/y 坐标，可实现：

- 绕底盘几何中心旋转；
- 绕云台轴线投影旋转；
- 绕某个车轮接地点旋转；
- 绕车体外指定点做圆周运动。

平移速度表示该旋转中心处的速度，公共底盘函数负责转换到车体原点。

## 正解

`alg_mecanum_forward` 使用可用轮速和权重求解 `vx`、`vy`、`wz`，并输出均方根残差。
单轮失效通常仍可求解三自由度；两个轮子失效是否可解取决于轮组组合和已知分量。

应用层应结合 `alg_chassis_fault` 对持续大残差轮子降权或剔除。

## 坐标和单位

线速度为 `m/s`，轮角速度为 `rad/s`，角速度为 `rad/s`，长度为米。方向正负由项目坐标
约定和 `direction_sign` 共同决定。

## 内存与实时性

对象内部只保存配置和预计算系数，无动态内存。所有输入输出为调用者存储，适合高频控制。
同一对象初始化后可重复只读使用。

## 建议验证

- x/y 直线、原地旋转及复合运动；
- X/O 两种辊子布局；
- 四轮安装方向组合；
- 中心、轮边和车外旋转中心；
- 任意单轮以及不同双轮失效；
- 轮速饱和与比例保持；
- 正逆解往返、残差和噪声权重。
