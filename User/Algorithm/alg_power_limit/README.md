# alg_power_limit

功率限制器只处理数值，不依赖裁判系统、电机或芯片。调用方把裁判功率上限、缓冲能量和各执行器的功率估计传入，算法返回每路缩放后的输出。

优先级用于保留舵向、云台等关键通道；缓冲能量在上下阈值之间平滑映射到持续功率与峰值功率。`alg_power_limit_estimate_motor_power()` 可作为没有功率传感器时的机械功率与铜耗估计。

`minimum_output_scale` 是期望下限，不是越过硬功率上限的许可；当下限总和也超出可用功率时，最终安全归一化会继续降低输出。

所有数组由调用方提供，库不分配内存。比赛参数应由参数模块加载，不应写死在算法中。
