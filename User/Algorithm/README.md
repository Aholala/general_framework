# Algorithm 层 —— 算法库完整使用指南

## 1. 模块概述

**Algorithm 层**是整个嵌入式软件架构中的**算法核心层**，它独立于硬件、操作系统和应用程序，只处理数值计算、状态估计、几何变换和运动控制逻辑。所有算法使用纯 C11 实现，不依赖 HAL、CMSIS 或 RTOS，不使用动态内存分配，所有数据由调用者提供和管理。

**核心设计原则**：

- **硬件无关**：不访问寄存器、外设、传感器或执行器硬件
- **零动态内存**：所有状态、矩阵、工作区由调用者静态分配
- **纯标准库依赖**：仅依赖 `<stdbool.h>`、`<stddef.h>`、`<stdint.h>`、`<math.h>`
- **显式错误返回**：每个可能失败的接口返回明确状态码
- **多实例支持**：每个算法对象独立状态，支持多路并发
- **可移植性**：可在裸机、RTOS、Linux 等任何 C11 环境中编译运行

**模块组成**：

| 分类           | 模块                   | 功能                                      |
| :------------- | :--------------------- | :---------------------------------------- |
| **数学基础**   | `alg_math`             | 标量、统计、向量、矩阵、四元数            |
| **运动与轨迹** | `alg_trajectory`       | 梯形/S曲线单轴轨迹、多轴同步              |
| **姿态估计**   | `alg_attitude`         | Mahony/Madgwick 六轴姿态融合              |
| **滤波**       | `alg_filter`           | 基础滤波、窗口滤波、FIR、Biquad、互补滤波 |
| **状态估计**   | `alg_kalman`           | 标量/线性/扩展卡尔曼滤波                  |
| **IMU 姿态**   | `alg_imu_ekf`          | 六轴 IMU 四元数姿态 EKF                   |
| **控制**       | `alg_pid`              | 位置式/增量式/串级/增益调度/模糊/角度 PID |
| **控制**       | `alg_lqr`              | 无限/有限时域 LQR、LQI 增广、角度 LQR     |
| **底盘运动**   | `alg_chassis`          | 底盘运动计算、车轮状态监测                |
| **底盘运动**   | `alg_mecanum`          | X/O 型四麦克纳姆轮运动学                  |
| **底盘运动**   | `alg_omni`             | 三轮/四轮/任意全向轮运动学                |
| **底盘运动**   | `alg_swerve`           | 任意舵轮布局运动学                        |

## 2. 设计哲学

### 2.1 层次分离

```
┌─────────────────────────────────────────────────────┐
│                    Application                       │
│              (业务逻辑、状态机、用户命令)             │
├─────────────────────────────────────────────────────┤
│                       BSP                            │
│            (硬件抽象、外设驱动、中断处理)             │
├─────────────────────────────────────────────────────┤
│                     Module                          │
│              (设备对象、传感器融合、执行器)           │
├─────────────────────────────────────────────────────┤
│                    Algorithm  ← 本层                 │
│            (数值计算、状态估计、控制算法)             │
└─────────────────────────────────────────────────────┘
```

- **Algorithm 层**只处理数值、状态和几何关系，不访问设备、寄存器、HAL、RTOS 或 App。
- **Module 层**调用 Algorithm 层的算法对象，管理传感器和执行器数据流。
- **BSP 层**提供底层硬件抽象。
- **Application 层**实现业务逻辑和用户交互。

### 2.2 状态管理

- 固定规模算法（如 PID、标量卡尔曼、四元数）：状态存储在实例结构体中。
- 变长算法（如矩阵运算、EKF、多轮约束）：使用调用者提供的工作区。
- 对象初始化后**不得按值复制**（结构体可能包含指针）。
- 有状态更新对象由单一周期任务持有，跨任务访问由外部同步（互斥锁或消息传递）。

## 3. 子模块详解

### 3.1 alg_math —— 基础数学库

提供标量运算、角度处理、在线统计、插值查表、向量/四元数运算以及动态矩阵操作。

| 功能分类   | 主要接口                                                                                              |
| :--------- | :---------------------------------------------------------------------------------------------------- |
| 标量/角度  | `alg_math_clamp`, `alg_math_lerp`, `alg_math_map_range`, `alg_math_wrap`, `alg_math_angle_difference` |
| 统计       | `alg_math_statistics_t`, `alg_math_array_mean`, `alg_math_array_rms`                                  |
| 插值       | `alg_math_interpolate_linear1_d`, `alg_math_interpolate_bilinear`                                     |
| 向量 2D/3D | `alg_math_vector2_t`, `alg_math_vector3_t` 加减/缩放/点积/叉积/模长/归一化                            |
| 四元数     | `alg_math_quaternion_t` 单位化/共轭/乘法/欧拉角转换/旋转向量/SLERP                                    |
| 矩阵       | `alg_math_matrix_t` 初始化/加减/乘/转置/求逆/求解/Cholesky                                            |

**适用场景**：所有需要数学运算的地方，是其他所有算法的底层基础。

### 3.2 alg_trajectory —— 轨迹生成

提供一维在线轨迹生成（梯形速度 / S 曲线）和多轴同步运动。

| 功能          | 接口                                         |
| :------------ | :------------------------------------------- |
| 单轴位置目标  | `alg_trajectory_set_position_target`         |
| 单轴速度目标  | `alg_trajectory_set_velocity_target`         |
| S 曲线 / 梯形 | `alg_trajectory_set_profile`                 |
| 制动距离      | `alg_trajectory_calculate_stopping_distance` |
| 多轴同步      | `alg_trajectory_group_t` 五次多项式同步      |

**适用场景**：云台 P/T/Z 轴规划、底盘移动轨迹、机械臂关节插补。

### 3.3 alg_attitude —— 姿态估计

提供 Mahony 和 Madgwick 六轴姿态融合算法（加速度计+陀螺仪），支持外部 yaw 修正。

| 功能            | 接口                           |
| :-------------- | :----------------------------- |
| Mahony 滤波器   | `alg_attitude_mahony_update`   |
| Madgwick 滤波器 | `alg_attitude_madgwick_update` |
| 外部 yaw 修正   | `alg_attitude_update_yaw`      |

**适用场景**：飞控姿态估计、云台稳定、机器人方向估计。

### 3.4 alg_filter —— 信号滤波

提供基础滤波、窗口滤波、FIR、Biquad 和互补滤波。

| 功能         | 接口                                         |
| :----------- | :------------------------------------------- |
| 移动平均     | `alg_filter_moving_average`                  |
| 指数移动平均 | `alg_filter_exponential`                     |
| FIR          | `alg_filter_fir_t`                           |
| Biquad       | `alg_filter_biquad_t`（低通/高通/带通/带阻） |
| 互补滤波     | `alg_filter_complementary`                   |

**适用场景**：传感器噪声抑制、信号平滑、频率选择。

### 3.5 alg_kalman —— 卡尔曼滤波

提供标量、线性状态空间和扩展卡尔曼滤波（EKF）。

| 功能       | 接口                                            |
| :--------- | :---------------------------------------------- |
| 标量卡尔曼 | `alg_kalman_scalar_t`                           |
| 线性卡尔曼 | `alg_kalman_linear_t`                           |
| 扩展卡尔曼 | `alg_kalman_extended_t`（用户自定义非线性模型） |

**适用场景**：传感器融合、状态估计、定位与导航。

### 3.6 alg_imu_ekf —— IMU 姿态 EKF

专为六轴 IMU 设计的四元数姿态扩展卡尔曼滤波器。

| 功能                | 接口                     |
| :------------------ | :----------------------- |
| IMU 姿态 EKF        | `alg_imu_ekf_t`          |
| 加速度计/陀螺仪更新 | `alg_imu_ekf_update`     |
| 磁力计修正          | `alg_imu_ekf_update_mag` |

**适用场景**：无人机、机器人、可穿戴设备的姿态估计。

### 3.7 alg_pid —— PID 控制器

提供完整的 PID 控制解决方案，包括位置式、增量式、串级、增益调度、模糊自适应和角度串级封装。

| 功能       | 接口                                            |
| :--------- | :---------------------------------------------- |
| 位置式 PID | `alg_pid_t`（二自由度、微分先行、抗饱和、前馈） |
| 增量式 PID | `alg_pid_incremental_t`                         |
| 串级 PID   | `alg_pid_cascade_t`（位置环+速度环）            |
| 角度 PID   | `alg_pid_angle_t`（角度外环+角速度内环）        |
| 增益调度   | `alg_pid_gain_schedule_t`                       |
| 模糊自适应 | `alg_pid_fuzzy_t`                               |

**适用场景**：速度控制、位置控制、温度控制、电流控制。

### 3.8 alg_lqr —— LQR 控制器

提供线性二次型调节器设计工具，包括无限/有限时域 Riccati 求解、控制器执行、二维角度封装、离散化和 LQI 增广。

| 功能          | 接口                                |
| :------------ | :---------------------------------- |
| 无限时域 LQR  | `alg_lqr_dare_solve`                |
| 有限时域 LQR  | `alg_lqr_finite_solve`              |
| LQR 控制器    | `alg_lqr_controller_t`              |
| 角度 LQR      | `alg_lqr_angle_t`                   |
| Tustin 离散化 | `alg_lqr_discretize_tustin`         |
| LQI 增广      | `alg_lqr_lqi_build_augmented_model` |

**适用场景**：最优控制、姿态控制、倒立摆、路径跟踪。

### 3.9 alg_chassis —— 底盘运动

提供底盘运动计算和车轮状态监测。

| 功能           | 接口                                 |
| :------------- | :----------------------------------- |
| 速度约束与求解 | `alg_chassis_solve_velocity`         |
| 车轮状态监测   | `alg_chassis_wheel_monitor_t`        |
| 轮速缩放       | `alg_chassis_scale_wheel_velocities` |

**适用场景**：所有底盘运动学模块的公共基础设施。

### 3.10 alg_mecanum —— 麦克纳姆轮

四轮麦克纳姆底盘运动学，支持 X/O 型辊子布局、任意旋转中心和缺轮降级。

| 功能     | 接口                                                                 |
| :------- | :------------------------------------------------------------------- |
| 逆运动学 | `alg_mecanum_inverse`, `alg_mecanum_inverse_with_center_of_rotation` |
| 正运动学 | `alg_mecanum_forward`                                                |
| 饱和缩放 | 自动限速保持方向                                                     |

**适用场景**：四轮麦克纳姆底盘控制。

### 3.11 alg_omni —— 全向轮

通用三轮/四轮/任意非对称全向轮运动学。

| 功能         | 接口                                                           |
| :----------- | :------------------------------------------------------------- |
| 任意轮布局   | `alg_omni_wheel_config_t`                                      |

**适用场景**：三轮全向底盘、四轮全向底盘、非对称全向布局。

### 3.12 alg_swerve —— 舵轮

任意数量舵轮模块运动学，支持参考坐标系命令、任意旋转中心和舵角最短路径优化。

所有算法使用国际单位制（SI）并统一为单精度浮点数：

| 物理量   | 单位     | 变量命名建议          |
| :------- | :------- | :-------------------- |
| 长度     | `m`      | `_m`                  |
| 线速度   | `m/s`    | `_m_per_s`            |
| 角度     | `rad`    | `_rad`                |
| 角速度   | `rad/s`  | `_rad_per_s`          |
| 角加速度 | `rad/s²` | `_rad_per_s2`         |
| 时间     | `s`      | `_time_s`（控制周期） |
| 频率     | `Hz`     | `_hz`                 |
| 温度     | `°C`     | `_c`                  |
| 质量     | `kg`     | `_kg`                 |
| 力       | `N`      | `_n`                  |
| 力矩     | `N·m`    | `_n_m`                |

**约定**：所有量的单位写入变量名或结构体字段后缀。

## 5. 错误处理规范

所有算法接口返回明确状态码，App 层**必须检查返回值**，不能将 `DEGRADED` 或 `UNDERDETERMINED` 当作正常满输出。

### 5.1 通用状态码

| 状态码                     | 含义                                  |
| :------------------------- | :------------------------------------ |
| `_STATUS_OK`               | 操作成功                              |
| `_STATUS_INVALID_ARGUMENT` | 空指针、非法数值（NaN/Inf）、维度非法 |
| `_STATUS_OUT_OF_RANGE`     | 参数超出合法范围                      |
| `_STATUS_NOT_INITIALIZED`  | 对象未初始化                          |
| `_STATUS_NUMERICAL_ERROR`  | 数值溢出、非有限结果                  |

### 5.2 模块特定状态码

| 状态码                               | 所属模块         | 含义                       |
| :----------------------------------- | :--------------- | :------------------------- |
| `ALG_KALMAN_STATUS_SINGULAR_MATRIX`  | `alg_kalman`     | 矩阵奇异，无法求逆         |
| `ALG_LQR_STATUS_NOT_CONVERGED`       | `alg_lqr`        | DARE 迭代未收敛            |
| `ALG_SWERVE_STATUS_DEGRADED`         | `alg_swerve`     | 部分模块不可用，已降级运行 |
| `ALG_CHASSIS_STATUS_UNDERDETERMINED` | `alg_chassis`    | 约束不足，无法唯一求解     |
| `ALG_CHASSIS_STATUS_SINGULAR`        | `alg_chassis`    | 约束矩阵奇异               |
| `ALG_TRAJECTORY_STATUS_FINISHED`     | `alg_trajectory` | 轨迹已完成（同时返回状态） |

## 6. 使用原则

### 6.1 通用原则

1. **先初始化，后使用**：所有算法对象必须调用对应的 `_init` 函数后才能使用。
2. **检查返回值**：不要忽略任何返回状态码，尤其是 `_INVALID_ARGUMENT` 和 `_SINGULAR`。
3. **数据生命周期**：所有指针指向的数据在对象生命周期内必须保持有效。
4. **单一所有者**：有状态对象由一个执行上下文持有，多任务访问需外部同步。

### 6.2 数值计算原则

1. **单精度浮点**：算法层统一使用 `float`，避免 Cortex-M 上的软件双精度运算。
2. **避免动态分配**：所有内存由调用者提供，算法内部不调用 `malloc`/`free`。
3. **有限性检查**：所有输入和中间结果检查 `isfinite()`，防止 NaN 传播。
4. **奇异检测**：矩阵求逆、归一化等操作检测奇异并返回明确错误。

### 6.3 运动学与底层原则

1. **传感器轴向、单位换算**属于 Module/BSP 层，不进入 Algorithm 层。
2. **高频固定维度运算**可在上层封装专用 2×2、3×3 版本以减少循环开销。
3. **能用 `Solve(A, b)` 时不要先计算 `Inverse(A)`**，求解更稳定快速。
4. **对协方差等对称正定矩阵优先使用 Cholesky** 而非通用求逆。

## 7. 新增算法完成标准

添加新算法模块到 Algorithm 层时，必须满足以下标准：

### 7.1 接口设计

- [ ] 公开头文件（`alg_xxx.h`）只包含完整类型与接口声明。
- [ ] 私有助手、内部常量和内部状态留在 `.c` 文件或 `_internal.h` 中。
- [ ] 所有函数使用统一的 `alg_xxx_` 前缀，枚举/宏使用 `ALG_XXX_` 前缀。
- [ ] 状态码枚举完整覆盖所有错误情况。

### 7.2 实现规范

- [ ] 明确坐标定义、符号方向、单位和数值前提。
- [ ] 不访问硬件（寄存器、外设、传感器）或全局设备。
- [ ] 不使用动态内存（无 `malloc`/`free`/`calloc`）。
- [ ] 对 NaN、无穷、零维度和边界输入有确定结果。
- [ ] 所有可能失败的接口返回状态码。

### 7.3 文档要求

- [ ] 每个模块有独立的 `README.md`，记录：
  - 功能概述和适用场景
  - 核心接口使用示例
  - 时间复杂度
  - 工作区大小计算（如适用）
  - 建议验证测试项
- [ ] 头文件中每个公开函数有完整的 Doxygen 注释（`@brief`、`@param`、`@return`、`@note`）。
- [ ] 源文件中有文件头注释（作者、日期、版本、说明）。

### 7.4 构建验证

- [ ] 加入根 `CMakeLists.txt`。
- [ ] 通过严格构建（`-Wall -Wextra -Werror`）。
- [ ] 无编译警告。

**总结**：Algorithm 层是嵌入式软件架构中的**数值计算与算法核心**，为上层应用提供了完整、独立、可移植的数学、滤波、控制、运动学等基础能力。其零动态内存、纯 C11、硬件无关的设计使其可运行于任何 C11 环境中，从 Cortex-M 裸机到 Linux 系统均可无缝移植。配合 BSP/Module 层的传感器和执行器接口，可快速构建从底层控制到上层决策的完整机器人/自动化系统。
